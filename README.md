# Visual Campus

AI-сервис, который за 30 секунд собирает проверенный визуальный профиль университета
(кампус, общежития, аудитории, библиотеки, лаборатории, спорт, студенческая жизнь, город) с
кликабельными источниками, датами и честными метками достоверности.

Полная спецификация: SPEC.md. Журнал решений: DECISIONS.md.
Полная документация (разделы 1-13 по спецификации) будет дописана на Фазе 8.
